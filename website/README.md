# TAGER PRO - تاجر برو • الموقع الرسمي

الموقع الرسمي لنظام **تاجر برو (TAGER PRO)** لإدارة المتاجر والمبيعات والمخازن ونقاط البيع (POS).

## ✨ المميزات الرئيسية للموقع:
1. **ربط سحابي لحظي بقاعدة بيانات Firebase Realtime**:
   - نفس قاعدة البيانات المشتركة مع برنامج الكمبيوتر وتطبيق الأندرويد.
   - إنشاء الحساب من الموقع يتيح للمستخدم الدخول فوراً وبنفس البيانات في `smart_merchant.exe` و `TAGER_PRO.apk`.
   - فحص الحسابات المحظورة ومنعها من الدخول تلقائياً.
2. **تنزيل أحدث الإصدارات ديناميكياً**:
   - يقرأ أرقام الإصدارات وروابط التحميل لنسخة الكمبيوتر (`PC`) وتطبيق الأندرويد (`Android`) مباشرة من لوحة الإدارة (`Alio7/system_control/app_updates`).
   - أي تعديل على الروابط في لوحة تحكم المشرف ينعكس فوراً على الموقع بدون الحاجة لإعادة رفعه.
3. **وضع الصيانة التلقائي**:
   - مرتبط بمسار الصيانة `Alio7/system_control/maintenance/website`.
   - بمجرد تفعيل وضع الصيانة من لوحة الإدارة العليا، يتحول الموقع لشاشة الصيانة الفاخرة مع عرض الرسالة وموعد الانتهاء.
4. **باقات الاشتراك وطلب ترقية VIP**:
   - عرض الخطط والأسعار مع نموذج مالي لتحويل فودافون كاش وإنستاباي.
   - يتم إرسال الطلب فوراً إلى لوحة المشرف `Alio7/admin/vip_requests` لتفعيله بضغطة زر.

## 🚀 طريقة الرفع على GitHub Pages مجاناً:
1. قم بإنشاء مستودع جديد على GitHub باسم مثلاً: `tager-pro` أو `tagerpro-web`.
2. ارفع محتويات هذا المجلد (`E:\ali1\website\`) إلى المستودع.
3. ادخل إلى **Settings** في مستودع GitHub -> ثم **Pages**.
4. تحت **Build and deployment**، اختر **Deploy from a branch** وحدد فرع `main` والمجلد `/ (root)`.
5. اضغط **Save** وسيكون موقعك متاحاً فوراً على الإنترنت برابط مجاني:
   `https://<your-username>.github.io/tager-pro/`
